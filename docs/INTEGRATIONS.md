# Integrations

The platform exposes a provider abstraction model for SaaS and enterprise integrations.

## Supported patterns

- OAuth-based user and app integrations
- webhook receivers and outbound delivery
- bot and app manifests
- adapters for GitHub, GitLab, Jira, Linear, Google, Microsoft, Zoom, and Notion
- generic HTTP-based integration handlers

All integrations are processed via the standard event, authorization, and audit layers.
